# Tapas — Portfolio

Personal developer portfolio showcasing full-stack web applications, technical skills, certifications, and experience.

## Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## Project Structure

```
├── public/                 # Static assets (resume, icons, portrait)
├── src/
│   ├── components/         # React UI components (Hero, Works, Skills, etc.)
│   ├── utils/              # Project data, tilt animations, and logic helpers
│   ├── App.tsx             # Root application component
│   ├── main.tsx            # Vite entry point
│   └── index.css           # Global Tailwind CSS styles
├── package.json
└── vite.config.ts
```

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```

The production output will be generated in the `dist/` directory.
