# Tapas — Portfolio

Personal developer portfolio website showcasing web applications, technical skills, and projects.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Motion

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
