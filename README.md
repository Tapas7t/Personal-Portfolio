# Tapas Karmakar — Developer Portfolio

Personal developer portfolio website built with React, TypeScript, Tailwind CSS, and Motion.

## Overview

Source code for the personal developer portfolio of Tapas Karmakar, Full-Stack Developer & AI Enthusiast based in Mumbai, India. The site highlights full-stack web applications, technical skillsets, verified certifications, and academic background.

## Features

- Atmospheric visual design with dynamic canvas elements and subtle ambient lighting
- Custom 3D interactive card tilt physics with touch and reduced-motion support
- Project showcase with technical architecture modal dialogs
- Interactive engineering toolset covering frontend, backend, and developer tools
- Verified professional certifications and academic timeline
- Native smooth scrolling with Lenis render-loop synchronization
- Responsive contact routing for mobile and desktop clients

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS v4
- Motion
- Lenis
- Vite
- Lucide React

## Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
